1. Системные требования
2. Установка Python
3. Создание рабочей директории

================================================================================
1. СИСТЕМНЫЕ ТРЕБОВАНИЯ
================================================================================

- Python: версия 3.8 или выше
- Операционная система: Windows / Linux / macOS
- Оперативная память: минимум 256 MB (рекомендуется 512 MB)
- Свободное место на диске: минимум 50 MB
- Порт 8000 должен быть свободен

================================================================================
2. УСТАНОВКА PYTHON
================================================================================

Windows:
--------
1. Скачайте Python с официального сайта: https://www.python.org/downloads/
2. Запустите установщик
3. ВАЖНО: Отметьте галочку "Add Python to PATH"
4. Нажмите "Install Now"

Linux (Ubuntu/Debian):
----------------------
sudo apt update
sudo apt install python3 python3-pip

macOS:
------
brew install python3

Проверка установки:
-------------------
python --version

Должно отобразиться: Python 3.8.x или выше

================================================================================
3. СОЗДАНИЕ РАБОЧЕЙ ДИРЕКТОРИИ
================================================================================

Windows (PowerShell или cmd):
-----------------------------
mkdir space_mission_api
cd space_mission_api

Linux/macOS:
------------
mkdir space_mission_api
cd space_mission_api

================================================================================
4. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ (РЕКОМЕНДУЕТСЯ)
================================================================================

Windows (PowerShell):
---------------------
python -m venv venv
.\venv\Scripts\activate

Windows (cmd):
--------------
python -m venv venv
venv\Scripts\activate.bat

Linux/macOS:
------------
python3 -m venv venv
source venv/bin/activate

ПРИЗНАК УСПЕШНОЙ АКТИВАЦИИ:
Появится (venv) в начале строки командной строки.

================================================================================
5. УСТАНОВКА ЗАВИСИМОСТЕЙ
================================================================================

Создайте файл requirements.txt:
-------------------------------
echo Flask==2.3.3 > requirements.txt

Установка зависимостей:
-----------------------
pip install -r requirements.txt

Или просто:
-----------
pip install Flask==2.3.3

================================================================================
6. СОЗДАНИЕ ФАЙЛА ПРИЛОЖЕНИЯ
================================================================================

Создайте файл app.py в директории проекта и скопируйте в него полный код 
решения (код из ответа с тремя задачами).

================================================================================
7. ЗАПУСК СЕРВЕРА
================================================================================

Команда для запуска:
--------------------
python app.py

УСПЕШНЫЙ ЗАПУСК (должны увидеть):
----------------------------------
 * Serving Flask app 'app'
 * Debug mode: off
 * Running on all addresses (0.0.0.0)
 * Running on http://127.0.0.1:8000
 * Running on http://172.x.x.x:8000
Press CTRL+C to quit

================================================================================
8. ПРОВЕРКА РАБОТОСПОСОБНОСТИ
================================================================================

ВАЖНО: Для тестирования откройте НОВОЕ окно терминала (не закрывайте то, 
где запущен сервер)!

8.1 Проверка health endpoint:
------------------------------
curl http://localhost:8000/health

ОЖИДАЕМЫЙ ОТВЕТ:
{"status":"healthy"}

8.2 Проверка задачи 1 (Круиз Робинсона):
-----------------------------------------
curl -X POST http://localhost:8000/api/v1/robinson_cruise -H "Content-Type: application/json" -d "{\"mass_shuttle\":1000.0,\"mass_fuel_unit\":1.0,\"power_per_unit\":1000.0,\"oxygen_time\":864000,\"total_fuel\":7000,\"fuel_consumption\":3.0,\"bodies\":[{\"id\":\"planet1\",\"gravity_assists\":[{\"velocity_gain\":10000.0,\"fuel_consumption\":40,\"time_to_execute\":1095},{\"velocity_gain\":24000.0,\"fuel_consumption\":84,\"time_to_execute\":2026}]},{\"id\":\"gas_giant\",\"gravity_assists\":[]}],\"edges\":[{\"from\":\"start_point\",\"to\":\"planet1\",\"distance\":200000000},{\"from\":\"planet1\",\"to\":\"gas_giant\",\"distance\":100000},{\"from\":\"gas_giant\",\"to\":\"rescue_point\",\"distance\":4000000}]}"

ОЖИДАЕМЫЙ ОТВЕТ:
{"can_reach":true,"min_flight_time":709698.8,"route":["start_point","planet1","gas_giant","rescue_point"]}

8.3 Проверка задачи 2 (Видимость звезды):
------------------------------------------
curl -X POST http://localhost:8000/api/v1/star_visibility -H "Content-Type: application/json" -d "{\"target_star_vector\":{\"x\":1.0,\"y\":0.0},\"celestial_bodies\":[],\"observation_params\":{\"start_time\":\"2026-03-21T00:00:00Z\",\"required_transmission_time\":70000}}"

ОЖИДАЕМЫЙ ОТВЕТ:
{"found":true,"next_fitting_interval_in":0,"interval_duration":"inf"}

8.4 Проверка задачи 3 (Поиск созвездий):
-----------------------------------------
curl -X POST http://localhost:8000/api/v1/constellation_finder -H "Content-Type: application/json" -d "{\"stars\":[{\"name\":\"Alpha\",\"x\":0,\"y\":0,\"z\":0},{\"name\":\"Beta\",\"x\":10,\"y\":0,\"z\":0},{\"name\":\"Gamma\",\"x\":10,\"y\":10,\"z\":0}],\"cluster_params\":{\"min_size\":2,\"max_size\":5,\"max_neighbor_distance\":20},\"target_constellation\":{\"edges\":[{\"from\":0,\"to\":1,\"distance\":10},{\"from\":1,\"to\":2,\"distance\":10}]}}"

ОЖИДАЕМЫЙ ОТВЕТ:
{"found":true,"matched_stars":["Alpha","Beta","Gamma"]}

================================================================================
9. ТЕСТИРОВАНИЕ С ПОМОЩЬЮ POWERSHELL (Windows)
================================================================================

Задача 1:
---------
$body1 = '{"mass_shuttle":1000,"mass_fuel_unit":1,"power_per_unit":1000,"oxygen_time":864000,"total_fuel":7000,"fuel_consumption":3,"bodies":[{"id":"planet1","gravity_assists":[{"velocity_gain":10000,"fuel_consumption":40,"time_to_execute":1095}]}],"edges":[{"from":"start_point","to":"planet1","distance":200000000},{"from":"planet1","to":"rescue_point","distance":4000000}]}'
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/robinson_cruise" -Method POST -Body $body1 -ContentType "application/json"

Задача 2:
---------
$body2 = '{"target_star_vector":{"x":1,"y":0},"celestial_bodies":[],"observation_params":{"start_time":"2026-03-21T00:00:00Z","required_transmission_time":100}}'
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/star_visibility" -Method POST -Body $body2 -ContentType "application/json"

Задача 3:
---------
$body3 = '{"stars":[{"name":"A","x":0,"y":0,"z":0},{"name":"B","x":10,"y":0,"z":0},{"name":"C","x":10,"y":10,"z":0}],"cluster_params":{"min_size":2,"max_size":5,"max_neighbor_distance":20},"target_constellation":{"edges":[{"from":0,"to":1,"distance":10},{"from":1,"to":2,"distance":10}]}}'
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/constellation_finder" -Method POST -Body $body3 -ContentType "application/json"

10. ОСТАНОВКА СЕРВЕРА
================================================================================

В терминале, где запущен сервер, нажмите:
Ctrl + C

================================================================================
11. УСТРАНЕНИЕ НЕПОЛАДОК
================================================================================

ПРОБЛЕМА: "pip not found"
РЕШЕНИЕ:
python -m pip install --upgrade pip

ПРОБЛЕМА: "Address already in use" (порт 8000 занят)
РЕШЕНИЕ:
- Найти процесс, использующий порт 8000, и остановить его
- ИЛИ изменить порт в коде: app.run(host='0.0.0.0', port=8001)

ПРОБЛЕМА: "ModuleNotFoundError: No module named 'flask'"
РЕШЕНИЕ:
pip install Flask

ПРОБЛЕМА: Ошибка активации venv в PowerShell
РЕШЕНИЕ:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\venv\Scripts\Activate.ps1

ПРОБЛЕМА: curl не распознается как команда
РЕШЕНИЕ:
- Используйте Invoke-RestMethod в PowerShell
- ИЛИ установите curl: https://curl.se/windows/

------------------------|-----------------------------------------------------

Память < 1 ГБ           | tasklist | findstr python (Windows)
Скорость < 3 сек        | Ответ приходит мгновенно (заметно визуально)
Вес репозитория < 64 МБ | Размер папки с кодом (обычно < 1 МБ)

9. ТЕСТИРОВАНИЕ С ПОМОЩЬЮ POWERSHELL (Windows)
================================================================================

Задача 1:
---------
$body1 = '{"mass_shuttle":1000,"mass_fuel_unit":1,"power_per_unit":1000,"oxygen_time":864000,"total_fuel":7000,"fuel_consumption":3,"bodies":[{"id":"planet1","gravity_assists":[{"velocity_gain":10000,"fuel_consumption":40,"time_to_execute":1095}]}],"edges":[{"from":"start_point","to":"planet1","distance":200000000},{"from":"planet1","to":"rescue_point","distance":4000000}]}'
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/robinson_cruise" -Method POST -Body $body1 -ContentType "application/json"

Задача 2:
---------
$body2 = '{"target_star_vector":{"x":1,"y":0},"celestial_bodies":[],"observation_params":{"start_time":"2026-03-21T00:00:00Z","required_transmission_time":100}}'
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/star_visibility" -Method POST -Body $body2 -ContentType "application/json"

Задача 3:
---------
$body3 = '{"stars":[{"name":"A","x":0,"y":0,"z":0},{"name":"B","x":10,"y":0,"z":0},{"name":"C","x":10,"y":10,"z":0}],"cluster_params":{"min_size":2,"max_size":5,"max_neighbor_distance":20},"target_constellation":{"edges":[{"from":0,"to":1,"distance":10},{"from":1,"to":2,"distance":10}]}}'

11. УСТРАНЕНИЕ НЕПОЛАДОК
================================================================================

ПРОБЛЕМА: "pip not found"
РЕШЕНИЕ:
python -m pip install --upgrade pip

ПРОБЛЕМА: "Address already in use" (порт 8000 занят)
РЕШЕНИЕ:
- Найти процесс, использующий порт 8000, и остановить его
- ИЛИ изменить порт в коде: app.run(host='0.0.0.0', port=8001)

ПРОБЛЕМА: "ModuleNotFoundError: No module named 'flask'"
РЕШЕНИЕ:
pip install Flask

ПРОБЛЕМА: Ошибка активации venv в PowerShell
РЕШЕНИЕ:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\venv\Scripts\Activate.ps1

ПРОБЛЕМА: curl не распознается как команда
РЕШЕНИЕ:
- Используйте Invoke-RestMethod в PowerShell
- ИЛИ установите curl: https://curl.se/windows/
